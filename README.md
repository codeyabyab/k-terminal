# K Terminal

A side-project which is a web application that mimics a terminal interface, inspired by [ M4TT72 | Terminal ].

# Features
- Simulates a command line interface (CLI) environment.
- Includes various commands ranging from utility to API-based actions.
- Offers customizable color themes.

## Tech Stack used in Development

**Frontend**
- React
- Tailwind CSS
- Date FNS
- React Icons

**Backend**
- Axios

**Build Tools**
- Node.js / npm
- Next
- Vite

**Deployment**
- Vercel

## Reflection
This is my first project using Next instead of the regular development stack that I use. I've had a lot of fun experimenting with it while making this side-project.
